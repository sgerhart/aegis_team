# Task Management

This directory contains task tracking and assignment information for the backend team.

## Current Sprint

- `current-sprint.md` - Current sprint tasks and priorities
- `backlog.md` - Future tasks and feature requests
- `completed/` - Archive of completed tasks

## Task Templates

- `templates/` - Task templates for different types of work
- `epic-templates/` - Templates for larger feature work

## How to Use

1. **New Task**: Create a new file using the appropriate template
2. **Update Progress**: Edit the task file to update status and add notes
3. **Complete Task**: Move to `completed/` directory when finished
4. **Review**: Use for sprint planning and progress reviews

## Task Status

- 🔴 **Not Started** - Task created but work not begun
- 🟡 **In Progress** - Currently being worked on
- 🟢 **Review** - Completed, awaiting review
- ✅ **Done** - Fully completed and reviewed
- ⏸️ **Blocked** - Waiting on external dependency
