# Meeting Notes and Decisions

This directory contains meeting notes, decisions, and action items from backend team meetings.

## Meeting Types

- `standups/` - Daily standup notes
- `sprint-planning/` - Sprint planning sessions
- `architecture/` - Architecture and design discussions
- `retrospectives/` - Sprint retrospectives
- `ad-hoc/` - Ad-hoc meetings and discussions

## Meeting Notes Format

Each meeting should include:
- **Date and Time**
- **Attendees**
- **Agenda Items**
- **Decisions Made**
- **Action Items** (with owners and due dates)
- **Next Steps**

## Action Items Tracking

- Use `action-items.md` for tracking all outstanding action items
- Include owner, due date, and status
- Update regularly during meetings

## Meeting Templates

- `templates/` - Standard meeting note templates
- Use consistent format for easy reference and follow-up
